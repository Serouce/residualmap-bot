# Code of Conduct

ResidualMap Bot is a self-hosted finance project. The community should be practical, respectful, and careful with sensitive data.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially from first-time self-hosters.
- Keep discussions focused on the project, deployment, privacy, security, and maintainability.
- Use synthetic examples when discussing financial records.
- Help maintainers keep the project private-by-default and safe for operators.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Posting another person's private information.
- Posting real Telegram IDs, bot tokens, OpenAI keys, Cloudflare tokens, webhook secrets, D1 database IDs, CSV exports, private logs, or real financial records.
- Pressuring maintainers or users to share production data.
- Publicly posting exploit details before the maintainer has had a reasonable chance to respond privately.

## Security and Privacy Reports

For security issues, follow `SECURITY.md` instead of opening a public issue with sensitive details.

For support questions, follow `SUPPORT.md` and remove private deployment details before posting.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that expose secrets, personal data, private financial records, or abusive content. Repeated or severe violations may lead to a block from the project.

## Attribution

This code of conduct is intentionally short and project-specific. It follows the spirit of the Contributor Covenant while adding explicit privacy expectations for a self-hosted finance tool.
